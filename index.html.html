01 / アイテムの基本情報

選択したバージョンに対応する /give コマンドを生成します。

アイテム一覧は日本語の主要候補を収録しています（全アイテム網羅ではありません）。1.20.1で未実装の新アイテムは候補から除外されます。

02 / エンチャント

対象アイテムとの適合性に関係なく指定可能。ただしゲーム中に発動するかどうかはMinecraftの仕様に従う。

03 / 属性と発動スロット

属性ごとに適用スロットを設定。異なるアイテムとの合算も想定して、IDはアイテムごとに分けて生成する。

複数アイテム間の同属性効果は、同じ修飾子IDの重複を避ける必要があります。プレビューの合算は「加算」だけを対象としています。

04 / 設置制限

この機能はアドベンチャーモード用。サバイバルでの完全な設置禁止には追加の仕組みが必要。

05 / パーティクル設定

パーティクルを付けたい場合
上のアイテムに専用の識別データを付け、指定したスロットにあるときだけエフェクトを発動できます。/give とは別に、下の補助コマンドを「リピート・無条件・常時実行」のコマンドブロックで動かしてください。

チャットのコマンド実行表示を消す

リピートコマンドブロックの実行ログがチャットに流れる場合は、次のコマンドをゲーム内で一度実行してください。ワールド全体に適用されます（チート・権限が必要）。

/gamerule commandBlockOutput false

元に戻す場合：

/gamerule commandBlockOutput true

※コマンドを手動実行した際のフィードバックも非表示にしたい場合は /gamerule sendCommandFeedback false を別途使用してください。

ゲーム内表示プレビュー

色・説明文の概念プレビューです。実際のゲーム内描画とは多少異なります。
